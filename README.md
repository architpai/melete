# Melete

A minimal Pomodoro timer that lives in the macOS notch.

*Melete* is Greek for study, reflection and practice.

> Status: planning. The design is not final. There is no code yet.

## Plan

1. Interview: collect the requirements. Done.
2. Research: study the notch Pomodoro apps that exist. See [docs/research.md](docs/research.md).
3. Mocks: make and compare design mocks. See [docs/mocks](docs/mocks).
4. Spec: see [docs/spec.md](docs/spec.md). Build plan: [docs/architecture.md](docs/architecture.md).
5. Build: native Swift + SwiftUI, macOS 14 or later.
